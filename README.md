# سیستم حسابداری و انبارداری بوتیک «آداک اورجینال» (Adak Original)

نرم‌افزار حسابداری، انبارداری و ثبت فاکتور لمسی، طراحی شده اختصاصی برای بوتیک لباس مردانه با تمرکز بر **سادگی فوق‌العاده**، **حس دفترچه یادداشت دیجیتال** و **کاهش تایپ به صفر**.

---

## 🚀 ویژگی‌های کلیدی پیاده‌سازی شده

1. **طراحی Mobile-First & Touch-Friendly:** دکمه‌های بزرگ لمسی، کارت‌های تصویری کالاها با برچسب موجودی، بدون نیاز به کیبورد برای ثبت سفارش.
2. **مدیریت نسیه و پرداخت‌های ناقص (Credit & Partial Payments):**
   - **تسویه کامل:** کل مبلغ از طریق کارتخوان/نقد پرداخت شده و بدهی صفر است.
   - **تسویه ناقص:** دریافت بخشی از مبلغ (مثلاً ۸۰۰ هزار تومان) و ثبت اتوماتیک باقیمانده (مثلاً ۱ میلیون و ۲۰۰ هزار تومان) به عنوان بدهی دفتری مشتری.
   - **نسیه کامل:** ثبت کل فاکتور در حساب بدهی مشتری با یک کلیک.
3. **کسر و بازگشت خودکار موجودی انبار:** از طریق تریگرهای PostgreSQL در دیتابیس Supabase و هماهنگ در پنل.
4. **تخفیف سریع:** دکمه‌های آماده تخفیف (۲۰، ۵۰، ۱۰۰ و ۲۰۰ هزار تومان) به علاوه تخفیف دلخواه.
5. **گزارش‌گیری سود:** داشبورد شفاف با ۳ شاخص کلیدی در بازه‌های روزانه (امروز)، هفتگی و ماهانه:
   - تعداد فاکتورهای صادر شده
   - مجموع فروش ناخالص
   - سود خالص دقیق (محاسبه تفاضل قیمت فروش از قیمت خرید تک تک اقلام)
6. **پشتیبانی کامل از حالت آفلاین/دمو:** نرم‌افزار حتی پیش از اتصال به Supabase نیز با داده‌های نمونه روی مرورگر کار می‌کند و به محض تنظیم متغیرهای محیطی به پایگاه داده ابری سوپابیس وصل می‌شود.

---

## 🗄️ راه‌اندازی دیتابیس Supabase

۱. وارد پنل کاربری پروژه خود در [Supabase](https://supabase.com) شوید.
۲. از منوی سمت چپ به بخش **SQL Editor** بروید.
۳. محتویات فایل [`supabase/schema.sql`](file:///f:/Adak/supabase/schema.sql) را در ادیتور کپی کرده و روی دکمه **Run** کلیک کنید.

---

## ⚙️ تنظیم متغیرهای محیطی

فایل `.env.local` را باز کرده و مقادیر دریافتی از بخش Project Settings > API سوپابیس را وارد کنید:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

---

## 💻 اجرای محلی (Local Development)

```bash
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

---

## ☁️ دیپلوی روی Vercel

۱. پروژه را روی مخزن گیت‌هاب پوش کنید.
۲. در داشبورد Vercel پروژه جدید را از گیت‌هاب Import کنید.
۳. دو متغیر محیطی `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` را در بخش Environment Variables اضافه نمایید.
۴. روی **Deploy** کلیک کنید.
